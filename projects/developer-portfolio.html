The problem

Every portfolio template looks the same. Frameworks add megabytes of JS to a page that could be one HTML file.

A portfolio is a page. It doesn't need a router, a bundler, or a node_modules folder — it needs to load fast and read clearly.

What I built

  • Hand-written HTML/CSS/JS with no dependencies
  • Dark mode with system preference detection + localStorage
  • Mobile-responsive layout with hamburger nav
  • Print stylesheet for clean PDF export
  • AJAX contact form via Formspree

How it works

Single-page site, deployed as static HTML to GitHub Pages.
