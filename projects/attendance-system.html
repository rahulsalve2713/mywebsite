Face & Voice Recognition Attendance

Face recognition · Voice identification · CSV + SQLite logging

Real-time attendance tracking using face and voice — because proxies are trivial and paper logs are tedious.

View on GitHub →

The problem

Attendance at scale is a pain. Proxies are easy, manual logs don't scale, and verification is impossible after the fact.

A signature on a sheet proves nothing. The question behind this project was whether two independent signals — a face and a voice — could make faking attendance meaningfully harder.

What I built

  • Face recognition for primary identification
  • Voice recognition as a secondary check
  • Real-time logging to CSV and SQLite
  • Verification against ground truth

How it works

  1. Student approaches the camera
  2. Face is recognized against the enrolled set
  3. A voice sample verifies identity
  4. Attendance is logged with a timestamp
  5. Admin view shows daily attendance and false-positive flags
