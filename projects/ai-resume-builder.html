AI Resume Builder

NLP · Flask · Template generation

An NLP tool that generates ATS-friendly resumes from plain user input — no templates to fight, no formatting that gets rejected.

View on GitHub →

The problem

Job-seekers spend hours formatting resumes, ATS systems reject clean-looking ones, and every template tool wants a subscription.

The frustrating part is that the rejection is invisible — you get no feedback, you just never hear back. So the goal here was simple: output something a parser can actually read.

What I built

  • NLP-based parsing of user input
  • ATS-optimized template generation
  • Flask backend handling the request flow
  • Clean HTML output for export

How it works

  1. User fills a structured input form
  2. NLP parses and structures the content
  3. Template engine generates an ATS-safe layout
  4. Output is a downloadable, formatted resume
