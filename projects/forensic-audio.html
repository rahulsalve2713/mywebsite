Forensic Audio Analyzer

RAG · Speech transcription · Evaluation pipeline

A system that verifies whether a voice recording is authentic — using Retrieval-Augmented Generation to analyze speech patterns and flag manipulation.

View on GitHub →

The problem

Audio can be AI-generated, spliced, or edited. For forensic use, "sounds real" isn't good enough — you need structured evidence.

A human listening to a clip can tell you it feels off. They can't tell you why, and a feeling doesn't hold up in a report. This project tries to turn that instinct into something documented and repeatable.

What I built

  • RAG pipeline for structured voice analysis
  • Forensic-grade speech transcription
  • API integration for processing submissions
  • Evaluation and result-verification methodology

How it works

  1. User submits a recording
  2. Speech is transcribed through a forensic-grade pipeline
  3. RAG retrieves relevant context and known manipulation patterns
  4. System evaluates authenticity and flags anomalies
  5. Structured output is returned with confidence indicators
