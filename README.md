# Rahul Salve — Portfolio

A single-page personal portfolio site showcasing my projects, skills,
and background as a B.Tech Electronics & Computer Engineering student
at MIT ADT University, Pune.

**Live site:** [rahulsalve2713.github.io/mywebsite](https://rahulsalve2713.github.io/mywebsite/)

---

## Features

- **Hero section** with portrait, tagline, and quick links (email, LinkedIn, GitHub, phone)
- **About** — professional summary and current focus
- **Skills** — grouped by languages, frameworks, libraries, and concepts
- **Projects** — five real projects with descriptions and tech tags
- **Education** — timeline from Class X through B.Tech
- **Certifications & achievements** — grid of all certificates and awards
- **Contact form** — delivered straight to my inbox via [Formspree](https://formspree.io) (no backend required)
- **Responsive** — works on mobile, tablet, and desktop
- **Print-friendly** — the whole page prints cleanly as a résumé
- **Accessible** — semantic HTML, reduced-motion support, proper contrast

---

## Tech stack

| Layer | Choice | Why |
| :--- | :--- | :--- |
| Markup | Hand-written HTML5 | No build step, easy to maintain |
| Styling | Plain CSS with custom properties | Zero dependencies, instant load |
| Typography | [Fraunces](https://fonts.google.com/specimen/Fraunces) + [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts | Editorial feel without sacrificing readability |
| Scripting | ~10 lines of vanilla JS | Sticky nav border only |
| Contact form | Formspree (free tier) | No server, no database, no CORS headaches |
| Hosting | GitHub Pages | Free, auto-deploys on push |

No frameworks. No build tooling. No `node_modules`. One HTML file does the work.
